AMERICA, ONE ROAD AT A TIME — TRAVELOGUE PACKAGE

This package contains the travelogue source files and all 151 numbered JPEGs available for the current edition.

CONTENTS
- index.html, styles.css, story.css, app.js
- photos/hero.jpg (copied from P090.jpg, the Port Jefferson double-rainbow image)
- photos/P###.jpg: 151 available numbered photographs
- photo_manifest.csv: photo ID, filename, and reviewed caption/notes

UPLOAD TO THE REPOSITORY
1. Unzip this package.
2. Copy index.html, styles.css, story.css, app.js and photo_manifest.csv into the existing travelogue/ directory.
3. Copy the entire photos/ directory into travelogue/photos/ (merge, do not delete unrelated files).
4. Commit and push on feature/american-roadtrip-travelogue.
5. Preview the branch deployment before merging to master.

The gallery shows every numbered photo present in this package. Some captions are intentionally generic where the exact reviewed detail was not available in the manifest; those captions are not intended to invent a location or event.

NOT INCLUDED IN THIS EDITION
The working 158-ID manifest indicates these seven source files are absent from the available 151-image collection: P108, P135, P137, P139, P140, P141, P146.
They are not fabricated or replaced with stock imagery.

NOTE
The supplied HTML includes the existing narrative and route map. Please test the preview on the feature branch before publishing; this package does not change the live site by itself.
