# US Travelogue

A standalone static website for the American road-trip travelogue. It is intentionally isolated from the existing `travelogue/` app.

## Railway
- Set the service Root Directory to `/us-travelogue`.
- Serve `index.html` as the site entry point using a static-file server or your preferred static-site setup.
- Hero image: `assets/D1P4-H.jpg`.
- Day 1 image sequence: D1P1 through D1P8.

## Content
Day 1 copy follows the version approved by the author. Images are colocated with the story passages they illustrate.
